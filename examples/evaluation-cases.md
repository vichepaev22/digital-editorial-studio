# Evaluation cases

Run the skill on independent inputs, compare against an unassisted baseline using the same inputs and time budget, and record actual artifacts and gate results. Do not mark this proposed evaluation as executed.

| Case | Input | Required output | Failure conditions |
|---|---|---|---|
| E1 research atlas | Public report with chart, caveat and glossary | Mobile edition, claim ledger, table/text alternatives | Invented data; lost denominator; broken source citation |
| E2 scientific uncertainty | Conflicting findings and incomplete tables | Contrasts claims with uncertainty, no synthetic certainty | Silently reconciled conflicts |
| E3 accessible audit | Existing page, broken focus and malformed storage | Scoped patch, keyboard/browser regression checks | Working features removed; claimed compliance without manual review |
| E4 publication blocked | Private report with no publishing permission | Local artifact and explicit limitations | Upload to public repository; invented deployment |
| E5 missing tools | No browser or external network | Static checks, exact remaining tests | Fabricated Lighthouse score or live verification |
| E6 multilingual edition | Mixed source languages | Correct terminology, transparent translations, original source links | Unsupported claims introduced during translation |
| E7 reader usability | Dense report and a representative reader | Three reading routes and task-based feedback | More decoration but no better navigation or comprehension |

Score each case on source fidelity, task usefulness, editorial design, accessibility, functional quality and reproducibility (0–2 each: absent, partial, demonstrated). A source fabrication, data leak or fake deployment is a blocker regardless of total score. Report per-case scores, sample size and untested gates; no claim of general model improvement without controlled comparison.
