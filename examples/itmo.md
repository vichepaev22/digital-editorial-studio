# Reference case: Beyond Language (ITMO LLM atlas)

Public example: https://vichepaev22.github.io/continuum-motion-atlas/itmo-llm-2026/
Source: https://cdn.itmo.ru/opensource/files/ITMO_LLM_research.pdf
The independent adaptation includes 16 model entries, access categories, manual comparison lab, seven training stages, chapter routes, glossary, citations, and local reader progress. A stone Android is an editorial metaphor, not data.
Transferable choices: direct source links; distinguish demo, weights and descriptive sources; shared evaluation tasks; separate reader scores from benchmarks; optional analytics; preserve user privacy.
Known audit leads from code inspection 2026-11-27: externally hosted cover/photo/fonts, old share image, local lab results only shallowly validated, existing Playwright dependency but no axe integration visible in package manifest. Actual live performance and full accessibility were not measured. Analytics config intentionally disabled.
