# Editorial art direction

Start with a concept board, not a template theme. Set typography roles (display, body, data labels), color tokens, spacing scale, grid, breakpoints, image treatment and accessible interaction states. Maintain a distinctive cover and alternating chapter rhythms: text, evidence, illustration, meaningful interaction. Use consistent image captions and avoid decoration masquerading as data. Preserve an existing visual identity unless there is a documented problem.

Choose readable text measure (roughly 45–80 characters when feasible); allow user zoom and text spacing. Aim for WCAG 2.2 AA: 4.5:1 ordinary text contrast, 3:1 large text, visible focus, reflow at 320 CSS px, keyboard operation, meaningful headings, accessible names and non-color-only encoding. These are selected criteria, not the entire standard.

Design responsive components and reduced-motion states. Charts should have axes, units, source, uncertainty and a text/table alternative. Use original or licensed images, optimize their dimensions, set width/height, and describe purpose with meaningful alt text. Avoid loading critical imagery from fragile remote hosts when licensed local copies are possible.

Reference case: the ITMO edition combines classical sculpture, purple editorial art, atlas cards and a stone Android. Reuse the logic of metaphor, not the particular metaphor.
